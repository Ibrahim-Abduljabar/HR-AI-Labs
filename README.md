# HR AI Labs — النسخة العربية

صفحة تجمع أدوات الذكاء الاصطناعي للتوظيف والموارد البشرية، وتوفر روابط لمشاريع HR AI Labs.

## المشاريع

- CV Reviewer AI — مراجعة السير الذاتية واكتشاف الأخطاء واقتراح التحسينات.
- OfferX AI — إنشاء عروض العمل.
- Hirix AI — توليد أسئلة مقابلات وظيفية.
- JDX AI — إنشاء التوصيف الوظيفي.
- HR ReportX AI — إعداد تقارير الموارد البشرية وملخصاتها.
- Vetly AI — إنشاء اختبارات وظيفية وتقييم إجابات المرشحين.

## الملفات

- index.html — الصفحة الرئيسية باللغة العربية.

## نشر الموقع

الموقع منشور على Vercel. لربطه بمستودع GitHub:

1. استورد المستودع إلى Vercel.
2. اترك إعدادات البناء الافتراضية لموقع HTML ثابت.
3. انشر المشروع.
